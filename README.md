AI Drug Price Prediction System

An AI-based system for drug price prediction and market price analysis using machine learning techniques. The system uses a Random Forest Regression model to estimate medicine prices based on pharmaceutical product information and compares the predicted price with the prices of comparable medicines.

Project Overview

Drug prices can vary depending on several factors, including medicine type, strength, dosage form, manufacturer, and market conditions. This project uses historical pharmaceutical price data to develop a machine learning model that provides an initial estimation of a medicine's price.

The system combines two approaches:

AI-Based Price Prediction — predicts the expected price of a medicine using a Random Forest Regression model.
Market Price Comparison — compares the predicted price with the minimum, median, and maximum prices of comparable medicines.

The predicted price is intended to support initial price estimation, market comparison, and decision-making. It should not be considered an exact replacement for the actual market or regulatory price.
